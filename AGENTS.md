# AGENTS.md

## Every lesson has a writing exercise

- Every lesson in `lessons/` has a Write section (`<h2 id="write">`) with a `<div id="write-task">`, rendered by the `Reveal` component in `assets/reveal.js`. Any existing lesson shows the pattern.
- Five items, each `{ prompt, model, note }`: the prompt is the writing task, the model is what a native would write, the note says why.
- Every prompt exercises the theme of the lesson: the rule, register or word list just taught, in the situation the lesson is about. No generic translation drills.
- Skip the section only where production practice makes no sense (the placement test, a pure listening drill); then give the lesson its own writing task instead.
- Other repo rules live in [CLAUDE.md](CLAUDE.md): README sync, publishing.
