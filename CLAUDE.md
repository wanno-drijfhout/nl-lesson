# CLAUDE.md

## Keep the READMEs in sync

- New lesson in `lessons/`: add a link to it in `lessons/README.md`, in number order.
- New document in the repo root (like `MISSION.md`, `NOTES.md`, `RESOURCES.md`): add a link to it in `README.md`.
- Do this in the same commit as the new file.

## Publishing

- Do not open pull requests. Commit on a branch, merge it into `main` locally, then push `origin/main`.
- A push to `main` publishes: GitHub Pages serves `main`.
